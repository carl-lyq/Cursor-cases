# 押题班学生画像看板

> 项目路径：`Miscs/押题班画像` · 领域：数据分析

**一句话**：把 Excel 学生收集表变成可交互画像看板，辅助开班决策与学员结构分析

## 业务背景

**谁在用**：押题班运营、班主任、管理层

**典型场景**：每期线下班开班前 1–2 周，需要看清本期学员结构与风险点


运营需要回答：本期学员目标分分布如何？有多少特殊承诺？躺着学老生 vs 外部学员比例？ 这些判断直接影响排课、师资配置和开班宣讲口径。

**要解决什么**：把收集表里的学员信息变成「可筛选、可对比、可演示」的画像看板，口径写在 PRD 里统一执行。

## 工作痛点

- 每次开班都要在 Excel 里重做透视，改一个维度整表重来
- 承诺类型、目标分等口径靠人记，不同人统计结果不一致
- 给管理层汇报只能投静态表，无法现场按问题筛选

传统方式下，完成一版可用结果通常需要 **约 2–3 天出一版可汇报材料**。

## 项目要做什么

从业务视角，本项目最终要交付的是：

将线下班 Excel 学生表转化为可筛选、可对比的 HTML 画像看板，支撑开班决策会。

### 需要什么输入

- 线下班 Excel 收集表（多 Sheet）

### 产出什么

- `学生画像看板.html`（浏览器打开即可演示）
- `dashboard-data.json`（结构化数据，便于复用）

### 关键能力

- 按承诺类型、目标分、入学分、是否躺着学等维度筛选对比

### 处理规则

- 统计口径以 PRD 为准，避免「各算各的」

## 工作方式对比

### 传统方式

运营在 Excel 里透视 + 手工做图，改需求就重新拉表、重做图表

### 用 Cursor 之后

1. 先写 PRD 明确「算什么、怎么分类」
2. 对话让 Agent 写 Excel 提取脚本和 HTML 看板
3. 开班前按反馈改 Tab/筛选项，当天可演示
