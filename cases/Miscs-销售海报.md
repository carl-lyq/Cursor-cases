# 星海殿堂产品需求文档（主 PRD）

> 项目路径：`Miscs/销售海报` · 领域：产品与设计

**一句话**：1. **持续记录**：让每张已确认海报按日期自动进入团队荣誉档案。 2. **强化荣誉感**：突出个人姓名、头像、金额、等级、纪录和成长轨迹。 3. **激发持续行动**：通过榜单、连续上榜、下一等级进度和收藏机制，让成员愿意再次冲榜。 4. **促进团队互动**：允许成员共同选择下一代海报风格。 5. **降低维护成本**：新增海报后无需逐页编辑，统一数据更新即可发布。

## 业务背景

销售成交海报原本以单张图片分散传播。随着海报数量增加，销售成员难以回看自己的持续成绩，团队也缺少一个长期、公开且有仪式感的荣誉空间。 「星海殿堂」将每日成交海报沉淀为可持续积累的团队荣誉档案：让每一次成交都被记录、被看见，并通过星历、榜单、名人堂、图鉴和新风格共创，形成持续回访和良性竞逐。
