# PRD转可视化评审页

> 项目路径：`Miscs/WanLi改造` · 领域：产品与设计

**一句话**：将 1600+ 行的复杂学习路径 PRD 转为带导航与图表的单页 HTML，供产品团队评审对齐

## 业务背景

**谁在用**：产品经理、教研、研发、运营（萬里 HSK 学习路径项目）

**典型场景**：学习路径方案评审会、跨职能需求对齐会


WanLi HSK 需设计「注册 → 达标」完整学习路径，原始 PRD 超 1600 行，含用户分层、 五阶段路径、任务包、检核阶梯、补弱规则、付费触点等。直接投屏滚 Markdown， 参会人很难在有限会议时间内建立全局心智。

**要解决什么**：把长 PRD「翻译」成可逐章跳转、带流程图与分层的单页 HTML，让评审讨论围着同一张图进行。

## 工作痛点

- 长文 PRD 结构难一眼看清，评审效率低
- 流程图、分层图要另外画 PPT，MD 与展示稿双份维护
- 改版时文档与演示材料容易不同步

传统方式下，完成一版可用结果通常需要 **做一版可评审展示材料常需 1–2 天**。
