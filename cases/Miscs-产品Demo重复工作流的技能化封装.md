# 产品 Demo 重复工作流的技能化封装

> 项目路径：`Miscs/proto-drip-annotations-package` · 领域：研发与工具

**一句话**：把做产品 Demo 时反复出现的交接标注等工作流，沉淀为可安装、可分发的 Cursor Skill 包

## 业务背景

**谁在用**：产品经理、UI/前端（做 Demo 交接的人）

**典型场景**：每个新项目都要在 HTML 原型上加备注/待办、对齐 PRD、写集成说明


多个项目的 Demo 都要重复：加备注气泡、待办水滴、声明「交付保留·生产剔除」、 写集成步骤。每次从 BC 落地页拷贝或口头教 Agent，成本高且易漏。

**要解决什么**：在真实项目验证后，把工作流封装成 Skill 包，复制到 ~/.cursor/skills/ 即可复用。

## 工作痛点

- 每个 Demo 从零集成，半天到一天摸索
- Provider/Portal 等踩坑反复出现
- 经验无法打包给同事

传统方式下，完成一版可用结果通常需要 **新 Demo 接入常需半天到一天**。
