## 一、最初诉求

希望 Cursor 能**跨项目**自动整理每个项目信息，汇总到一份文档里。每个案例需要说明：

1. 该项目**如何通过 AI 提效**

工作范围：`AI Projects` 文件夹下全部项目 + Cursor 内全部 Agent 对话。  
与 `躺着学AI项目库` **暂时独立**，不依赖其 Portal。

## 二、方案演进（对话中的关键结论）

### 2.1 总体架构：事实层 + 叙事层

| 层次 | 内容 | 谁负责 |
|------|------|--------|
| **事实层** | 项目背景、传统流程、Cursor 用法、耗时、产出物 | 结构化采集 + 自动挖掘 |
| **叙事层** | 「比以前快在哪」「以前做不到什么」 | AI 初稿 + **人工确认** |

**核心原则：自动只写草稿，发布必须经人确认。**

### 2.2 目录与状态

```
采集（scan）→ draft/ + cases/ + reviews/
       ↓
人工确认（对话或命令行）
       ↓
published/（正式汇报版）→ GitHub main 备份
```

每个案例状态：`draft` → `confirmed` → 可选 `locked`（定稿后不再被自动覆盖）。

### 2.3 双引擎扫描

| 引擎 | 运行环境 | 能扫什么 | 电脑关机时 |
|------|----------|----------|------------|
| **repo-only** | GitHub Actions | PRD/README、Git 历史 | ✅ 云端照常 |
| **transcripts** | 本机 Mac | `~/.cursor/projects/*/agent-transcripts` | ❌ 延后，下次开机追平 |

本机 `portfolio.py scan` = 全量；关机不丢数据，只是**晚一点**进案例库。

### 2.4 确认方式（已选定）

- **Cursor 对话**：`确认 portfolio` / `确认 portfolio <项目名>`
- **命令行**：`python3 scripts/portfolio.py confirm`
- 规则写入：`.cursor/rules/portfolio-confirm.mdc`

### 2.5 暂缓项（对话中明确「后面再弄」）

| 项 | 状态 | 文档位置 |
|----|------|----------|
| 飞书通知 | 未接入，仅预留 | `docs/05-飞书通知（待接入）.md` |
| 手机操作 Cursor | 不纳入本期 | 结论：无完整手机 IDE；Cloud Agent PWA 可监督，本期不做 |

### 2.6 GitHub 备份策略

- 案例库目录：`AI Projects/Cursor案例库`（独立仓库）
- 分支：`portfolio-draft`（自动草稿） / `main`（确认后的 published）
- 每天 GitHub Action：`portfolio.py scan --repo-only`

### 2.7 提高案例质量的可选手段

在各子项目放置 `.cursor/ai-impact.yaml`（模板见 `templates/ai-impact.example.yaml`），填写：

- `traditional` — 以前怎么做、痛点
- `with_cursor` — Cursor 用法
- `impact` — 量化提效、新突破

自动扫描优先使用 yaml，否则从 PRD/README + 对话推断。

## 三、对话中的典型问答（摘要）

**Q：自动跑时怎么让我确认？**  
A：自动只更新 `draft/` 和 `reviews/LATEST.md`；`published/` 仅在你「确认 portfolio」后更新；已确认案例用 `locked` 保护不被静默覆盖。

**Q：电脑关机或没联网怎么办？**  
A：GitHub Action 仍扫仓库；对话等本机上线后按时间戳追平；断网时本地可先写 draft，联网后再 push。

**Q：飞书怎么打通？**  
A：群自定义机器人 Webhook + GitHub Action 跑完后 POST；Secret 名 `FEISHU_WEBHOOK`；详见 `docs/05-飞书通知（待接入）.md`。（用户表示后面有空再处理。）

**Q：能在手机上操作吗？**  
A：无官方完整手机 IDE；可用 cursor.com/agents PWA 监督 Cloud Agent，或 GitHub App 看草稿；用户决定本期不做手机流程。

**Q：落地位置？**  
A：`/Users/mac/Library/CloudStorage/OneDrive-个人/AI Projects/Cursor案例库`，并要求**文档化**。
