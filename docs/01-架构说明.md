# 架构说明

> 产品需求见 [PRD.md](./PRD.md)；本文为技术实现分层说明。

## 目标

从 `AI Projects` 全部子项目及本机 Cursor Agent 对话中，自动归纳：

- 项目背景（业务语言）
- 传统做法与痛点
- 用 Cursor 后的工作方式
- 提效或「以前做不到」的突破点

输出可供**产品、运营、研发、管理层**阅读的 case 文档，而非技术日志。

## 系统分层

```
┌─────────────────────────────────────────────────────────┐
│  采集层                                                  │
│  · scan_projects  — PRD/README、git、ai-impact.yaml     │
│  · scan_transcripts — ~/.cursor/projects/*/transcripts   │
│  · lib/sanitize — 脱敏后写入 state/session-digests.json  │
└───────────────────────────┬─────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────┐
│  合成层                                                  │
│  · synthesize_cases — 案例卡（cases/*.md）               │
│  · draft 总览 — draft/AI-Projects-Portfolio.md          │
└───────────────────────────┬─────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────┐
│  确认层（人工）                                          │
│  · reviews/LATEST.md — 待确认清单                        │
│  · 对话「确认 portfolio」或 portfolio.py confirm         │
└───────────────────────────┬─────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────┐
│  发布层                                                  │
│  · published/ — 正式汇报版                               │
│  · GitHub main 分支备份                                  │
└─────────────────────────────────────────────────────────┘
```

## 双引擎扫描

| 引擎 | 运行环境 | 扫描内容 | 电脑关机时 |
|------|----------|----------|------------|
| **repo-only** | GitHub Actions | 文档、git 历史 + **已推送的 session-digests** | ✅ 照常 |
| **transcripts** | 本机 Mac | Agent 对话 → 脱敏 digest | ❌ 延后，上线追平 |

本机 `portfolio.py scan`（无参数）= 全量（repo + transcripts + 脱敏入库）。  
云端无法读 `~/.cursor`；对话摘要依赖本机 `daily-local-sync.sh` 推送到 `portfolio-draft`。详见 [07-本机每日对话同步.md](./07-本机每日对话同步.md)。

## 状态机

每个项目在 `state/case-status.json`：

| status | 含义 |
|--------|------|
| `draft` | 自动草稿，待确认 |
| `confirmed` | 已发布到 published/ |
| `locked` | 汇报定稿，自动扫描不改正文 |
| `ignored` | 不纳入案例库 |

## 路径配置

环境变量（可选）：

- `AI_PROJECTS_ROOT` — 默认 `Cursor案例库` 的父目录
- `CURSOR_PROJECTS_ROOT` — 默认 `~/.cursor/projects`

## 与躺着学 AI 项目库的关系

**完全独立。** 本仓库不依赖 `躺着学AI项目库/网站`；未来若需打通，可通过 API 导入 `published/` 内容。
