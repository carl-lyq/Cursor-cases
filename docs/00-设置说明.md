```bash
cd "/Users/mac/Library/CloudStorage/OneDrive-个人/AI Projects/Cursor案例库"

```

## 2. 关联 GitHub 远程仓库

```bash
git remote add origin git@github.com:<组织>/cursor-portfolio.git
git add .
git commit -m "chore: init Cursor 案例库"
git push -u origin main

git checkout -b portfolio-draft
git push -u origin portfolio-draft
```

## 3. 日常节奏

| 时机 | 操作 |
|------|------|
| 完成重要协作后 | `python3 scripts/portfolio.py scan` |
| 每天 08:15（建议） | 本机 `scripts/daily-local-sync.sh`（脱敏对话 + push draft），见 [07-本机每日对话同步.md](07-本机每日对话同步.md) |
| 每天 09:00 | GitHub Action 自动 `--repo-only`（读已推送的 digest） |
| 出差回来 | `scan --transcripts-only` 补对话 |
| 要汇报前 | 读 `reviews/LATEST.md` → `确认 portfolio` |
