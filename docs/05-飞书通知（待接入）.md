# 飞书通知（待接入）

> **状态：未实现，仅文档预留。** 你后续有空时按本文配置即可。

## 目标

每次自动扫描 push `portfolio-draft` 后，向飞书群发送一条 **待确认提醒**（业务语言，非技术日志）。

## 前置：创建飞书群机器人

1. 飞书群 → 设置 → 群机器人 → 添加自定义机器人
2. 复制 Webhook URL
3. 建议开启签名校验，记录 `secret`

## GitHub Secrets

在案例库 GitHub 仓库 Settings → Secrets：

| 名称 | 值 |
|------|-----|
| `FEISHU_WEBHOOK` | Webhook 完整 URL |
| `FEISHU_SIGN_SECRET` | 签名 secret（未开启可留空） |

## 接入位置

在 [.github/workflows/portfolio-scan.yml](../.github/workflows/portfolio-scan.yml) 末尾取消注释 `notify-feishu` job，或新增 step：

```yaml
- name: Notify Feishu
  if: success()
  env:
    FEISHU_WEBHOOK: ${{ secrets.FEISHU_WEBHOOK }}
    FEISHU_SIGN_SECRET: ${{ secrets.FEISHU_SIGN_SECRET }}
  run: python3 scripts/notify_feishu.py --review reviews/LATEST.md
```

脚本 `scripts/notify_feishu.py` 可在接入时新增，读取 `reviews/LATEST.md` 摘要发送卡片。

## 消息内容建议

- 标题：`📋 AI 案例库 · N 项待确认`
- 正文：新增/更新项目名（一句话）
- 按钮：链接到 GitHub `reviews/LATEST.md`、`compare main...portfolio-draft`

## 本机 scan 后通知（可选）

本机 `portfolio.py scan` 成功后也可调用同一脚本（读取环境变量 `FEISHU_WEBHOOK`），实现「补扫对话后」第二次提醒。

## 安全

- Webhook 不要提交到 Git
- 通知正文不写敏感业务数据，只写标题 + 链接
